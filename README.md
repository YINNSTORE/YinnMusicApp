## 🎧 About YinnMusicApp

YinnMusicApp is a **local offline music player** for Android, focused on:
- Clean UI
- Dark / AMOLED friendly themes
- Smooth performance
- Personal customization

> ⚠️ This app **does NOT support online streaming or downloading music**.

---

## ✨ Key Features
- Material You design
- Multiple themes (Light / Dark / AMOLED)
- Offline local music playback
- Playlist management
- Lyrics support
- Tag editor
- Folder-based music browsing
- Chromecast support
- Android Auto support
